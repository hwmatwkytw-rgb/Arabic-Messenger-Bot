# Arabic Messenger Bot (appstate.json + config.json)

هذا مشروع بوت ماسنجر جاهز من الصفر، أوامره عربية 100%، ويستخدم:
- `config.json` للإعدادات (البادئة/المالكين/المشرفين...)
- `appstate.json` لتسجيل الدخول (Cookies / AppState)

## التشغيل
```bash
npm install
npm start
```

## إعداد appstate.json
ضع ملف `appstate.json` الصحيح (المستخرج من حسابك) مكان الملف التجريبي الموجود هنا.

> ملاحظة: لا ترفع appstate.json للعلن.

## أوامر جاهزة
- `!مساعدة`
- `!بنج`
- `!وقت_التشغيل`
- `!ضم_مشرف`
- `!حذف_مشرف`
